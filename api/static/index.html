How many training pictures each class has. Roughly balanced, so the model is not biased toward one class.

Greenness: healthy leaves have the most clearly-green pixels; disease eats away green tissue.

Lesion colour share: sick leaves have about twice as many brown/yellow pixels as healthy ones, but the two diseases look alike by colour alone.

Brightness: differs a little between classes, but mostly reflects lighting in the field. The model should not rely on it.
